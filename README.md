\# ✦ Cursor



> A lightweight Tampermonkey enhancement tool with 30 practical features.  

> No network requests, no bypass, no upload. Off by default, reset on refresh.



\---



\## ✨ Features



All features are grouped into four categories.

Each feature is disabled by default and can be turned on individually.



| Category | Features |

| :--- | :--- |

| 📖 \*\*Reading\*\* | Reader Mode, Progress Bar, Smooth Scroll, Paragraph Highlight, Image Preview, No Image Drag, Code Monospace |

| ⌨️ \*\*Input\*\* | Email Autofill, Symbol Replace, Clear Input, Glow Border, Tab Indent, Clean Copy, Select All |

| 🎬 \*\*Video\*\* | Speed Shortcuts, Mute Toggle, Loop Toggle, Hide Controls |

| 🧰 \*\*Tools\*\* | Back to Top, Go to Bottom, Temp Note, Close Popup, Click to Hide, Gray Mode, Hide Scrollbar, Page Ready Toast |



\---



\## 🎯 How It Works



\- Click the `✦` icon at the top right of any page to open the panel.

\- All features are \*\*off by default\*\*. Turn them on only when you need them.

\- Language switching (中文 / English / 日本語) is available at the top right of the panel.

\- The panel can be collapsed into a small translucent circle at the bottom right.

\- Close the panel completely by clicking `✕`. It will reappear after refresh.



\---



\## 📦 Installation



1\. Install the \[Tampermonkey](https://www.tampermonkey.net/) browser extension.

2\. Click the link below to install the script automatically:

&#x20;  \[`cursor-enhance.user.js`](https://github.com/Guan-Blip/cursor-enhance/raw/main/cursor-enhance.user.js)

3\. Refresh any page and you will see the `✦` icon at the top right.



\---



\## 🛠️ Panel Guide



\- `✦` – Open / Close the control panel

\- `⤡` – Collapse the panel into a floating circle

\- `✕` – Close the panel permanently (reappears after refresh)

\- `🔘` – Enable all features in a single group

\- `✅` – Enable all 30 features at once

\- `❌` – Disable all 30 features at once

\- `🔄` – Reset all features to the default off state
